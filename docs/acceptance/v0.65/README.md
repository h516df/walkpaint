# 0.65 候选验收

范围：首次默认高德体验简化，按天收藏/标题/备注/标签/搜索，路线明信片 PNG 预览/保存/系统分享，行记随 JSON 备份与合并恢复。决策与参考项目见 [体验范围](../../design/experience-20261019.md)。正式发布尚未执行。

## 数据约束

GPS 过滤、已保存坐标、真实分段、recording_cursor 和 SQLite schema3 保持。新增 `files/footprint-journal.json` 保存按天行记，以临时文件、同步和原子替换写入；损坏文件保留，不用空数据覆盖。空行记作为明确清空保留，旧备份不会复活旧备注。

备份保留原 version1，加可选 journal 字段；旧备份兼容，旧轨迹解码仍可读取新增备份。先验证导入行记，才提交 GPS；GPS 成功但本机行记写入失败时明确提示部分恢复，允许重试，保留本机编辑。快照在仓库锁外读取行记，避免首次读取阻塞定位回调。

明信片使用所有真实分段，包括孤立点，不把断档连线。不请求额外存储权限：保存使用系统文档选择器，分享使用受限缓存 FileProvider 和临时读取授权。只包含路线形状、日期、标题、当天里程，无备注正文、地图瓦片或坐标标签；缓存仅清理本功能过期临时文件。

## 原生验收

执行目标仅本任务专用 Google APIs API36 AVD `WalkPaint_Google_API36` / `emulator-5556`；无 KVM，使用软件仿真。软件仿真首次启动多次触发系统 Watchdog；只对本任务 AVD 临时将硬件超时倍率设为10，并将显示设为720×1600/density280。常规应用验收前仍通过专用 AVD 身份与 boot_completed=1 校验，不以此环境声明真机性能。

已通过原生 `BackupRestoreProbe`：旧备份兼容/新备份行记往返、重复导入、本机编辑优先、坏行记原件保留且已恢复足迹不丢失、未来点整批拒绝、恢复期间继续记录与游标保持。只使用隔离数据库，见 [原生结果](backup-restore.log)。

界面、系统保存/分享与大字体路径正在验收，尚不计为通过。

## 正式发布边界

当前环境没有原签名或正式高德配置，不能生成可覆盖正式 App 的合格更新包。本轮独立开发包不覆盖正式数据，无配置时仅显示提示页，不作为高德联网、道路瓦片、首点开雾、户外与锁屏验收。开发期间已合并上游新发布的 0.64（单高德引擎、显式地图决定、历史回放），候选顺延 0.65；公开稳定版本仍以 Releases 为准，没有修改或覆盖历史资产。
