## 整合复测的工具修正

合并自适应导航后，系统文件选择器曾确认辅助功能点击却没有完成保存；补重试后又为重名文件生成“(1)”后缀，旧工具把合法后缀误判为失败。两次中止的原始结果见 [工具记录](tooling-attempts.log)。现仅对仍可见、启用且没有进度条的保存控件重试；文件名必须保留本次唯一请求标识，允许系统重名后缀，仍须通过实际返回URI读取PNG并核对尺寸与夜色像素。没有跳过系统选择器、伪造结果或放宽数据保持检查；这些均为androidTest改动。
