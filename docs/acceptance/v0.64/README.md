# 0.64 候选验收

范围：首次默认高德体验简化，按天收藏/标题/备注/标签/搜索，路线明信片 PNG 预览/保存/系统分享，行记随 JSON 备份与合并恢复。决策与参考项目见 [体验范围](../../design/experience-20261019.md)。正式发布尚未执行。

## 数据约束

GPS 过滤、已保存坐标、真实分段、recording_cursor 和 SQLite schema3 保持。新增 `files/footprint-journal.json` 保存按天行记，以临时文件、同步和原子替换写入；损坏文件保留，不用空数据覆盖。空行记作为明确清空保留，旧备份不会复活旧备注。

备份保留原 version1，加可选 journal 字段；旧备份兼容，旧轨迹解码仍可读取新增备份。先验证导入行记，才提交 GPS；GPS 成功但本机行记写入失败时明确提示部分恢复，允许重试，保留本机编辑。快照在仓库锁外读取行记，避免首次读取阻塞定位回调。

明信片使用所有真实分段，包括孤立点，不把断档连线。不请求额外存储权限：保存使用系统文档选择器，分享使用受限缓存 FileProvider 和临时读取授权。只包含路线形状、日期、标题、当天里程，无备注正文、地图瓦片或坐标标签；缓存仅清理本功能过期临时文件。
