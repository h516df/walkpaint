# 原生 UI v0.51

用户要求：UI 太丑，由 Codex 直接改进，不用 OpenDesign。Issue #68；唯一写手 agent/codex/native-ui-v051，正式整合目标 agent/codex/mobile-ui-redesign-v041，基线 db0b5b8/v0.50。

方向：以真实路线为中心的探索工具。地图保留黑雾和用户的足迹颜色，界面采用独立蓝色；地图上的深蓝控件减少刺眼白块，底部三入口固定、图标和文字分行。内容页用清晰无衬线字，不再用宋体式大标题和重复的空卡片。

配色：品牌蓝 #205BC5，浅蓝 #E8EFFC，文字 #18253B，次级文字 #59667A，白色面板 #FFFFFF，页面 #F3F5F9。深色页面 #0F1929，面板 #182538，文字 #E9EFFA。保存的涂色值独立，不随外观改变。

字号：26 标题、20/21 数值与状态、15/16 主内容、13 辅助说明、12 导航标签。所有字为系统 SansSerif，离线，不添加字体下载。行高 19–24。页面左右 20dp，面板内 16dp，组间 12–14dp；常用控件至少 48dp，导航至少 60dp。允许系统字体放大、垂直滚动；不添加装饰动画。

页面关系：探索保留地图对象；足迹先日历与摘要，再最近探索的真实路线预览；当天详情以路线、里程和回看入口为主。我的集中探索设置、帮助与管理，两组即可。诊断先状态，完整开发者报告可展开与复制；主动暂停属于用户选择，不引导修复后台。反馈短测先结论后详情，高级坐标报告有明确提示；更新保留原授权与校验路径。

不改定位/恢复/迷雾几何/数据库/签名/授权协议，不上传截图或路线，不运行设计委派。先构建查看真实截图再迭代。验证正常宽度、320dp、深色、较大字体和错误/暂停状态，最后复核高德导航、缩放与当天回看；截图或加载时间不能代替真机 FPS/户外定位。具体结果随提交记录在 V051.md。
