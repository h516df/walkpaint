# 从参考项目落实到日常体验

用户方向：默认高德、无需普通用户配置，进入后同意并授予必要定位即可体验。以真实足迹为内容，少文字、少设置，不为参考项目的功能广度增加首屏负担。

本轮选择：

| 需求 | 实现与入口 | 边界 |
| --- | --- | --- |
| 开箱即用 | 首次“同意并开始”合并必要告知，精确前台定位后进入原记录流程 | Android 系统权限仍需用户确认；后台增强延后 |
| 留下记忆 | 足迹 → 某一天 → 收藏、标题、备注、标签 | 本机独立原子文件，不改变 GPS、分段或数据库 |
| 找回历史 | 足迹 → 查找，支持日期/文字/#标签及收藏筛选 | 只显示已有真实记录日，不根据备注生成到访 |
| 有用的分享 | 当天足迹 → 制作路线明信片 → 纸白/夜色预览 → 保存或分享 PNG | 保留断档；含日期、标题与路线形状，不含备注正文或地图瓦片 |
| 数据可带走 | 原有 JSON 备份带上行记 | 旧备份兼容；本机编辑优先，明确清空也优先；行记失败单独提示 |

参考依据（2026-10-19 核对 GitHub README；仅参考产品思路，无外部源码移植）：

- [StoryPad](https://github.com/theachoem/storypad)：标签、星标、查找与本机导出。落实为某一天的小备注，不增加独立日记模块或同步账号。
- [pretty-gpx](https://github.com/ThomasParistech/pretty-gpx)：把已记录路线变为可留存的海报。落实为原生离线路线明信片，不增加 GPX 转换、地形下载或制图配置。
- [LocalSend](https://github.com/localsend/localsend)：降低分享的账号与服务器门槛。这里直接使用 Android 系统保存/分享，不新增局域网协议。
- [wanderer](https://github.com/open-wanderer/wanderer)：路线元数据、查找筛选和自定义集合。这里收敛为按天的标题、备注、标签与收藏，不增加服务器或账号。
- [Dawarich](https://github.com/Freika/dawarich)：按旅行回看、数据导入与保留原件。这里沿用按天回看和本机备份，不引入自建服务或家庭位置分享。
- [OpenTracks](https://github.com/OpenTracksApp/OpenTracks) 的 GitHub 仓库已提示迁至 Codeberg，不把过时镜像当作当前实现依据。

路线明信片为本项目原生实现，使用已保存的路线几何和 Android Canvas，默认进入系统保存/分享界面，由用户选择目标。图片形状仍可能透露行程，预览中明确提示。

照片日记、动态回放、复杂挑战、自动推荐目的地和新的空间索引暂不纳入本轮。前两项涉及媒体与更多交互，后三项会扩大权限、算法或首次使用负担；本轮先把记录、查找和带走足迹做通。

正式版本保持高德与原签名；当前环境无正式高德配置与原签名，本轮只构建独立开发包验收，不以开发备用底图冒充正式高德验收或发布。
