# OpenDesign 到 WalkPaint 原生界面的映射

来源：本机项目 `2026-10-13-e9ec`，官方成功 run `6c9f1231-8d7c-489b-ad9f-208a2702c27f`。七文件完整，摘要见 source-fingerprint.json。模型沿用用户既有 opencode/deepseek-v4.1-flash，官方默认推理参数。第一轮服务器连接中断后只恢复同项目官方流程；不改软件默认配置。

设计只用了匿名功能描述与虚拟数据。原稿是设计参考，不是 Android SDK 实现。官方 acceptance.md 的静态/DOM shim 结论不算真实渲染证据；另在真实浏览器 320/360/393/412 视口检查探索→足迹→日期详情→我的→探索，无横向溢出及控制台错误。

原生映射：Theme.kt 使用其 Day/Night 精确颜色，UiTokens/Screens/MobileDesign 使用字级、留白、圆角和轻量地图控件。地图仍使用实际高德与已有连续雾层、真实足迹与日期；原稿虚拟 GPS、进度、图例不作为产品数据。用户后续明确三入口在下面，原生底栏置底、地图控件上移，此纠正优先于原稿顶部导航。

原生最终验收与相同 APK 摘要见 ../../evidence/V045.md。浏览器原稿验证不能替代实际高德；实际高德 AVD 也不能替代本人 vivo、真实 GPS、户外锁屏及本人账号下载/安装。沿用原签名/schema2，无数据迁移。
