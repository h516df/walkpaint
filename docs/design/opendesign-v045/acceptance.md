# 足迹涂色 · 交互验收说明

**交付物**：`index.html`（入口，浏览器直接打开即可运行）+ `assets/styles.css`（tokens 与样式）+ `assets/map.js`（示意底图与迷雾引擎）+ `assets/data.js`（匿名演示数据）。
**原型声明**：底图是本地绘制的**示意矢量图**，轨迹为**原创匿名演示数据**；未接入任何真实地图 SDK、不申请系统定位权限、不读写真实文件，也未做过真实 SDK 验证。

---

## 一、如何验收

1. 打开 `index.html`。
2. 用浏览器设备模拟器依次切到 **320×800 / 360×800 / 393×852 / 412×915**，每屏检查：无横向滚动、无文字截断、浮动控件不遮挡卡片与列表。
3. 按下面「主流程」走一遍，再按「状态清单」逐项触发。

## 二、主流程

| # | 操作 | 预期 |
|---|---|---|
| 1 | 打开 → **探索** | 地图铺满内容区；顶部 48dp 悬浮三段导航（探索/足迹/我的）；右侧缩放 + 定位；左下图例；底部一张概览卡（已涂色 % + 本月里程 + 进度条 + 今日一行 + 文字链接） |
| 2 | 首次进入 | 先出现「正在加载底图…」→ 约 0.95s 后自动进入可交互地图；深色底为未探索区，沿轨迹是软边揭开的走廊 |
| 3 | 点 **＋ / −**（连续快速点 10 次） | 以**当前位置**为锚点连续缩放，位置不漂移、不自动重置 |
| 4 | 滚轮 / 双指捏合 | 以指针或双指中点为锚点连续缩放 |
| 5 | 拖动地图 | 自由平移，边缘有约束，不会把地图拖丢 |
| 6 | 点 **定位** | 视图回到当前位置（这是唯一会主动改变视角中心的入口） |
| 7 | 切到 **足迹** → 再回 **探索** | 地图视角完整保留，缩放层级不变 |
| 8 | **足迹** 页 | 月份切换（‹ 2026年10月 ›）、三格统计、月历（有记录的日子日号加粗 + 珊瑚短条，长度按月里程）、本月日子列表 |
| 9 | 点月历某一天 | 进入**当天详情**：当天地图（只画当天轨迹并揭开当天迷雾）+ 距离/用时/平均配速/出发–返回 + 途经街道 |
| 10 | 返回 | 回到 **足迹** 月历 |
| 11 | 切到 **我的** → 改设置 | 自动记录 / 后台记录 / 记录精度 / 轨迹颜色 / 主题 / 地图注记 / 位置权限 / 清除本地记录 / 检查更新 **全部真实可切换**，且切换后立即生效 |
| 12 | 改轨迹颜色 | 地图上轨迹线与日历短条同步换色（5 种） |
| 13 | 改主题为深色 | 界面与地图一起切到深色，风格一致 |
| 14 | 回 **探索** | 设置与视角都在；轨迹颜色已应用 |

> 说明：第 13 步只改了颜色 token，未改变任何布局或组件尺寸。

## 三、状态清单（诊断页 › 原型状态预览可一键触发）

| 状态 | 触发 | 呈现 |
|---|---|---|
| 加载 | 进入地图 / 点「加载状态」 | 环形进度 + 「正在加载底图…」，约 0.95s 后转正常 |
| 无定位 | 「无定位」 | 左上胶囊显示「定位不可用 · 等待信号」，定位按钮点击后提示稍后重试 |
| 无记录 | 「无记录」（跳到 2026-07） | 足迹页空状态卡「这个月还没有足迹」+ 仍显示月历；点无记录日期显示当天空状态 |
| 定位权限缺失 | 「定位权限缺失」/ 隐私页选「拒绝」 | 地图顶部提示条「定位权限未开启…去开启」，GPS 标记与定位点隐藏 |
| 地图错误 | 「地图错误」 | 满屏错误层 + 单个「重新加载」主按钮，重试后回到加载→正常 |
| 首次授权引导 | 「首次授权引导」（或 我的 › 隐私与权限 里改权限） | 底部弹层：三条说明 + 「暂不开启 / 允许并继续」，选择后写回权限状态 |

## 四、响应式与防溢出检查

- `320dp`：正文左右边距 16dp，内容宽 288dp。月历 7 列 → 每格约 42×48dp；顶部导航三项（68dp + 2dp 间距 + 2dp 内衬 ≈ 208dp）居中不溢出；概览卡内「今日 …」一行自动换行，链接不换行、不挤压。
- 三格统计、四宫格数据在 320dp 下文字均不截断（数值用等宽数字）。
- 所有可点元素 ≥ 44dp：导航 44、缩放/定位 48（外扩）、月份切换 48、返回 48、设置行整行、开关 66×48、分段 48、色点 48、日历格 ≥48、按钮 48。
- 无 `nowrap` 强制撑宽；无横向滚动；浮动控件（右列 / 图例 / 概览卡）在四档尺寸下均不重叠。

## 五、设计约束自检

- 未使用开始/暂停按钮、GPS 或地图引擎信息框、重复的今日/本周卡片。
- 顶部无巨大白色留白，无超大胶囊按钮。
- 未使用 emoji 图标（全部统一线性图标，描边 1.7）、未使用紫渐变、未使用「左色条 + 圆角卡」提示样式。
- 强调色（青绿）每屏 ≤ 2 处；同一功能只有主按钮一个实心样式。
- 显示字体（衬线）与正文字体（无衬线）不同；汉字标题不使用负字距，全大写标签字距 0.09em。
- 无外部远程资源：无 CDN、无字体外链、无远程图片，地图与轨迹全部由本地 canvas 绘制。
- 悬停/按压态只移动背景明度或描边，不把文字改浅。

## 六、已知边界（诚实说明）

- 时长与配速由「里程 ÷ 每日步行速度」推算，是演示数据，不是实测传感器数据。
- 「已涂色 %」按 25m 网格估算「轨迹软边覆盖面积 ÷ 区域面积」（当前约 30.9% / 0.99 km²），用于演示数据呈现，非真实测绘。
- `320dp` 下月历单格宽度约 42dp（略小于 48dp 宽），但高度 48dp、面积与 44dp 方target 相当；Android 端可用 `LazyVerticalGrid` + `Modifier.sizeIn(minWidth = 44.dp)` 处理。
- 导出轨迹、清除记录、检查更新为界面演示，不会真正读写文件或联网。
