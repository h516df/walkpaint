# 少量探索提示透出迷雾

基线：正式 v0.67 source `94f685a045cdedea0e921c6082b94155e37cb01c`。本次是后续候选代码，不修改已经发布的版本或资产。

## 实现与取舍

- 用户明确要求未知区域中也隐约看见值得去的真实地点。只把公开的公园、景点、文化场馆候选画在雾上；道路、地名、底图仍由原来的不透明雾遮住。
- 沿用 PoiSearchV2、现有应用配置、地图服务同意与错误说明。源坐标继续为 WGS84；搜索结果在服务边界恢复源坐标，绘制及点击通过控制器既有 toAmap/projection 链，不写回 GPS 数据。
- 复用同一 Android overlay：先雾与真实轨迹，再探索提示，最后当前位置。overlay 仍位于高德 logo/attribution 控件之下。没有额外地图服务或新 Key。
- 低饱和小圆环不贴名字。按实时屏幕投影稀疏筛选，低/中/高缩放最多 3/5/8 个点，点间至少 64dp；视觉直径 22dp，触控直径 48dp。点开看完整名称、大致直线距离和收藏状态。长名称与大字体详情可滚动，原列表仍为可读屏的替代入口。
- 地图与列表共用单一串行内存缓存。换位置但仍在节流期间会明确提示等待，不伪装成没有地点。同一位置 250 米内重用 5 分钟；所有真实请求至少间隔 60 秒，含失败。平移/缩放只重绘，不查询。无可靠位置不启动地图发现，退出前台/页面、进入历史或回放后取消接收并清空候选显示。缓存不落盘。
- SDK 同步 searchPOI 无公开取消方法。取消协程会阻止迟到结果交付 UI；仍持有串行锁直到已有 SDK 调用返回，以防重新打开产生并发请求。不能声称取消了已发送的网络流量。
- 候选、已收藏、已到访保持独立。查看、点击、收藏都不写到访状态、不解锁区域、不修改 GPS/数据库规则。
- SDK 原生 POI 继续支持已探索区域内的点选收藏，但门控取自当前实际绘制的迷雾位图：相同投影帧和变换下，采样点及周围像素都必须已完全开雾。镜头变化导致投影帧不匹配、位图不可用、边界或羽化区一律拒绝。新的可见探索提示独立响应，优先于其下的原生 POI。完整收藏仍能在列表查看。
- 错误在地图上明确显示，列表可重试；配置/授权错误不伪装为空数据。没有结果、没有位置、未同意服务时不产生虚构地点。

## 参考与适配理由

- 高德 [PoiSearchV2 官方 API](https://a.amap.com/lbs/static/unzip/Android_Map_Doc/Search/com/amap/api/services/poisearch/PoiSearchV2.html)：沿用现有同步周边检索而非引入第二服务；结果仍受既有 2 公里与类型筛选约束。
- 高德 [周边 POI 搜索指南](https://developer.amap.com/api/maps-sdk-for-android/guide/map-data/poi)：以可靠位置为检索中心，而非每次镜头移动发起请求。
- Android [触控与无障碍指南](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)：低调视觉不等于小触控范围，保留至少 48dp 命中区域，并保持可读屏列表替代入口。
