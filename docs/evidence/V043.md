## 实际缺陷和修复

1. 原通道把不足一个像素的三十米宽度强行扩大到两像素。启动兜底帧覆盖六十度，放大后的通道会清掉大片未走过的地面。保留宽兜底覆盖范围，但分辨率不足时雾层保持不透光，以路线线条表示探索记录；不扩大通道。空路线清掉旧透明通道。
2. 高德中国范围的视口为显示坐标，旧代码把它当 WGS84 再转换给地面覆盖物，导致雾层与地图错位。现在使用同一 SDK 的正向转换进行有界迭代还原，视口、全部探索边界和绘制统一为数据库坐标。未使用未经验证的第三方偏移公式。
3. 缩放改变通道是否可画时，叠加路线没有同步移除。现在相机视口的工作线程同时计算路线表示，街道视野只保留显露通道。
4. 高德加载前设置相机可能被默认宽视角覆盖，重开/返回页面验收复现。首次定位和已有相机恢复均在 SDK 加载完成后执行。
5. 只看首 ABI 把本机高德排除。ARM64-only 包可使用声明的 ARM64 native bridge；通用包的 x86 进程保持备用路径。可用性判断不等于验收。

正式包 cn.walkpaint，0.43/code45、schema2，原证书 SHA256：21b74e3e2a10e12da8284d4e6bd7d99e55b00a385215902e94d7896f7a46c967。

验收共同核对安装包 SHA256、运行进程中高德 ELF 的映射、App 读回引擎选择以及地图加载完成回调。Android 直接从 base.apk 映射未压缩 JNI 段时，进程映射不含独立 .so 文件名；旧 filename grep 的失败是探针缺陷。新探针核对 ZIP 库起始偏移与实际映射偏移，排除仅 DEX 被映射的假阳性。
