# v0.44：精简首页、缩放迷雾与搜星诊断

用户反馈来自 v0.43 / Android16：缩放时先露出未知地图约一秒；首页录制卡片、顶部定位/地图名称、重复足迹卡片和备用地图入口多余。用户授权由 Codex 决定可逆布局。

## 本轮结果

- 顶部探索/足迹和我的入口。探索为完整累计迷雾地图，保留放大、缩小、定位；没有首页录制卡片、定位状态或地图名称提示。高德 SDK 必需署名保留。
- 足迹默认日历，选有记录的日期直接看当天详情，再去当天地图；月/年回顾通过同页统计切换，不再堆今天/本周筛选和每天卡片。
- 普通备用地图设置入口移除。内部兼容保护未作为高德通过证据。
- 覆盖遮罩仅计算旧雾帧的四个屏幕投影角，遮住雾帧之外的未知地面；手势过程中也交接新雾层，不再只等手指抬起。定位/GPS入库与图层范围不耦合。
- 手动缩放或拖动取消待首次取景，防止晚到的数据把相机拉回zoom17。
- 地名查询须地图授权，明确初始化搜索SDK隐私、采用GPS坐标；异步返回也检查授权和请求是否仍有效。北京/上海公开地标实际查询成功，拒绝和撤回路径未初始化SDK；独立原生投影检查中心误差1.81像素，底图/视口/雾层坐标一致。
- GPS 已注册且45秒内仍有卫星状态、参与定位为0时，继续已有搜星订阅，不每90秒拆掉重注册。注册失败、卫星状态停止更新或已参与定位却没有回调时保留原恢复路径。此改动不能证明本人手机的断档根因已经解决。
- 过滤总数及分类都使用本次服务；启动次数明确是历史累计；无 GPS 不再推断室内。网络蓝点与GPS足迹区分。
