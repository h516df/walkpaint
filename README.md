# 足迹涂色 · WalkPaint

Android 私人足迹涂色 App。日常自动累积 GPS 足迹；当前 **v0.4 本地测试版**，尚未经 vivo 真机长期后台与续航验收。**真实道路涂色尚未接通。**

## v0.4 当前交付

- 定位前台服务持续请求 GPS，保留常驻通知；修复 GPS 注册失败无诊断、提供器恢复和重复回调问题，超过 90 秒无回调时限频尝试重注册。没有长期 CPU 唤醒锁，不通过无条件持锁换取测试成功；强制停止后仍需手动打开应用。
- “我的 → 查看记录诊断”显示服务启动/停止、最近 GPS 回调、最近 SQLite 入库、过滤/失败原因及超过 45 秒的回调断档。诊断不含经纬度或路线；常规事件在内存累计，每 30 秒批量持久化，启动/停止/失败/注册/断档立即提交到独立写入线程。异常退出可能损失末尾约 30 秒常规诊断，SQLite 足迹独立保存。
- GPS 预览改为细线和小标记，明确标注不是道路染色。`RoadPaint.kt` 只提供经过合成 fixture 单测的投影匹配、歧义拒绝、沿路几何截取与区间累计去重；**没有接入真实道路数据、道路覆盖数据库或 UI**。现有开放矢量瓦片可查询部分道路几何，但跨缩放/裁剪的稳定路段身份未验收，不能冒充可累计的真实道路数据集。
- 包名与升级签名沿用旧版，versionCode=5，SQLite schema=1，WGS84 历史格式不变。只覆盖安装，不卸载、不清空已有足迹。

本轮 33 项 JVM 单测及 `:app:assembleDebug` 通过。模拟器完整链路与最后质量复核分开记录，准确结果、APK 指纹、截图和缺口见 [HANDOFF.md](HANDOFF.md)。本轮只生成本地 APK，没有推送或发布；路径为 `app/build/outputs/apk/debug/app-debug.apk`。

## v0.3.1 历史改进

- **针对实际体验补救**：有可靠运动证据时放宽短距离判断，但保留静止漂移和跳点过滤；统一记录与里程统计，短距离用“米”而非“0.0 km”；提高路线对比度、显示头尾节点，放大短路线并修复历史路线点击后不定位的问题。定位服务与写入状态分开显示，失去 GPS 时不假装正在录制。
- **定位时间容错**：仅在 Android 单调时钟证明定位确实新鲜时修复异常的 GNSS 时间戳，不接纳陈旧定位点。无精度或精度 0 的位置不当作精确 GPS。
- **低成本诊断**：“我的 → 复制无位置坐标的诊断信息”提供权限、后台服务、GPS 精度、最新记录时间及电池策略状态；不复制经纬度或历史路线，便于在真实手机上排障。


- **首次同意，授权即开始**：阅读“同意并开启自动足迹”后授予精确定位，就立即尝试开启有常驻通知的定位前台服务；不需再次点开始。拒绝不会偷偷开启，“我的”可暂停。
- **短途立即反馈**：首个准确 GPS 点显示蓝绿色种子标记，多个已接受的真实点绘制线路；展示精度、点数、最近入库时间和 GPS 异常、过滤原因。不会假装画出未采集的路线。
- **正常导航图标**：地图、足迹、我的采用矢量图标，“我的”是人物图标。
- **性能与历史数据**：Indexed SQLite 最近点查询，异步历史快照与 GeoJSON；兼容 v0.1/v0.2 轨迹和调试版签名，versionCode=4，包名 cn.walkpaint。
- **地图**：加入高德 2026 官方 Maps SDK、单独第三方隐私授权和只在显示端进行 GPS(WGS84)→GCJ-02 转换。没有合法 Android Key 时继续 MapLibre/OpenFreeMap；腾讯、百度为候补，尚未集成。
- **备份**：JSON 可导出和合并导入；本地自动快照随卸载消失，仍需主动备份到设备外。

## 安装与使用

1. 当前 v0.4 为本地构建产物 `app/build/outputs/apk/debug/app-debug.apk`，未发布。已有私有 Release v0.3.1 仅作为历史版本保留。
2. **直接覆盖安装** v0.1、v0.2 或 v0.3，不要卸载或清除数据。签名与先前测试版一致。
3. 首次阅读“自动足迹”说明并主动同意，随后授权精确位置，录制就会立即尝试开始。地图蓝点是自己，蓝绿色是记录足迹，紫色仅演示。
4. 在“我的”查看里程、天数、探索网格、跟踪状态、导入/导出。后台重启自动恢复通常还需系统权限“始终允许定位”，以及按机型确认电池策略。
5. Android 省电、强制停止、GPS 环境可能影响持续采集；App 会尽量说明状态，但不能承诺永不间断。

## 高德地图与隐私

官方依赖版本 **com.amap.api:3dmap-location-search:11.3.100_loc11.3.000_sea9.8.1**。高德仅在已配置受签名限制的官方 Android Key 且用户**单独同意**高德 SDK 隐私信息后初始化；拒绝时可继续在开放地图上记录本地足迹。说明见 docs/AMap_SETUP.md。

**没有有效高德 Key，因此高德底图未被实测成功。** SDK 可能访问网络、定位、设备/系统与传感器信息，APP 内提供隐私说明和高德隐私政策链接。足迹仍在本地 SQLite/JSON 存为 WGS84，不将历史数据库自动上传至我方服务器；第三方在线地图会收到必要地图区域及网络请求信息。

## 已知限制 / 下一阶段

- 目前 UI 仍是 GPS 点与折线叠加，**不是真正把道路吸附并永久去重涂色**；纯道路算法已测试，但真实道路数据和 UI 接入缺失。探索网格不等于道路覆盖率；地点城市统计尚未实现。
- 真机长期锁屏、省电、重启、定位漂移、安卓厂商限制以及多年数据量性能未测试，需真实手机验证。
- 真正独立于手机本地数据的定时云备份尚未实现。
- 腾讯/百度为必要时备用地图服务，不使用无授权瓦片或他人的 Key。

## 开发与验证

主要文件：MainActivity.kt（权限、Compose/地图生命周期）、Screens.kt（3 页）、RecordingService.kt（自动定位）、FootprintDatabase.kt 与 Tracks.kt（数据与过滤）、TrackMapJson.kt（点/路线格式）、AmapMapController.kt（官方高德显示层）。默认地图仍是 MapLibre + OpenFreeMap，署名 © OpenStreetMap contributors；高德启用后署名 © 高德。

Android SDK 36、JDK21、AGP9.0.1、Gradle9.1.0；全量构建运行：gradlew.bat :app:testDebugUnitTest :app:assembleDebug；手机 arm64 精简构建：gradlew.bat :app:assembleDebug -PwalkpaintArm64Only=true。构建 APK 位于 app/build/outputs/apk/debug/app-debug.apk。API Key、用户足迹与签名私钥绝不提交到 Git。

**2026-10-08 v0.3.1 验收**：18 项 JVM 单元测试通过、0 失败；Android 15 MuMu 模拟器覆盖安装 v0.3.1 arm64 并检查前台定位服务；竖屏实际看到明显的彩色短途连接线，足迹列表点击可回到对应路线，“我的”可复制不含经纬度的定位诊断；注入 3 个短途 GPS 点全部入库、静止抖动未误入库、定位时间比当前早 4 分钟的新鲜 GPS 点经单调时钟验证后正确入库。可重复运行：python scripts/android_emulator_smoke.py（仅允许模拟器串号，运行会加入合成足迹，自动撤销模拟定位权限）。真实手机锁屏、耗电、后台重启、道路吸附与有 Key 的高德底图仍未验收。
