# 足迹涂色

Android 本地足迹应用：记录步行、骑行与驾车，沿可信的已保存轨迹揭开地图迷雾。探索、足迹、我的位于底部，支持按日期回看、本机皮肤、JSON 备份和合并恢复。每天的足迹可收藏、写备注与标签，并按日期或文字查找；也可制作路线明信片，预览后保存或分享。

正式版默认高德地图：首次打开点击“同意并开始”，在系统提示中允许精确定位，就能开始探索。无需账号、地图 Key 或道路包；后台增强设置可稍后按需开启。

## 安装与更新

正式包和中文说明在 [Releases](https://github.com/h516df/walkpaint/releases)。ARM64 手机选择 `WalkPaint-v<版本>-arm64.apk`，由系统确认覆盖安装，保留已有足迹。不要卸载或清除数据。

0.54 起支持“我的 → 检查更新”，无需 GitHub 登录，仍验证大小、SHA256、包名、递增版本、原签名和架构。0.53 及以前会拒绝公开更新源，首次迁移请在浏览器下载新包覆盖安装。实际已发布版本以Releases为准。

## 从源码构建

需要 JDK21、Android SDK36，使用 Gradle Wrapper；Windows 使用 gradlew.bat。

```sh
./gradlew :app:assembleDebug -PwalkpaintDeveloperBuild=true
./gradlew :app:testDebugUnitTest -PwalkpaintDeveloperBuild=true
python -m unittest discover -s tests -v
python -m unittest discover -s scripts -p 'test_*.py' -v
```

开发模式无需正式私钥，生成独立的 cn.walkpaint.dev 调试 App，不覆盖正式版；开发版从源码更新。没有高德 Key 时地图不加载，地图区给「开启高德地图」入口，App 不提供离线底图或备用引擎，见 [构建说明](docs/BUILD.md) 和 [地图配置](docs/AMap_SETUP.md)。正式发布保持原签名。

## 已知限制

- GPS受信号、权限、强制停止和厂商后台策略影响，不能保证永不断录。
- 模拟器证据不代替实体手机户外、锁屏、耗电和流畅度验收；缩放仍有长帧。
- 数据库版本为3，回退也须同签名、兼容数据结构且版本号不降低，不能直接装旧包。
- 本机自动备份不能防卸载或丢手机；达到容量预算时保留旧快照，不自动删除。
- GitHub匿名API受共享出口请求限额影响；检查更新提示受限时，可从公开Releases下载覆盖包，无需登录。

测试只用公开地点或合成夹具，不接受提交个人轨迹作为测试数据。

## 本轮体验更新

成长记录包括等级、徽章、每周目标、使用日历与本机使用统计。页面采用更少文字和留白布局，徽章墙、日历与统计说明按需展开。最近任务隐藏是自选项，不保证后台常驻。

探索页显示附近2公里的点亮面积估算；获取到真实区县边界后可切换范围。普通用户不用注册地图开发者账号。后台记录设置集中管理定位、耗电限制、开机恢复及系统自启动入口。
